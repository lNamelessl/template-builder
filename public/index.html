    ⚡ Setup wizard

    Three steps: pick your LLM provider, then paste your Railway and GitHub tokens. Everything is live-validated against its provider on save, then stored AES-256-GCM encrypted on this instance's volume. Values are never exported and never shown again (masked only). They are sent only to your chosen LLM provider, GitHub and Railway APIs.
    Step 1 — LLM provider
    Non-DeepSeek providers have NO server-side web search. A free Tavily key (app.tavily.com ↗) restores web-grounded research; without it research runs on model knowledge + the live marketplace scan.
    Step 2 — Railway token
    RAILWAY_TOKENrailway.com/account/tokens ↗
    1. Open the link → New Token → name it (e.g. builder) → it is displayed once and copies immediately.
    2. Paste it here right away (account token — templates publish to YOUR workspace).
    Step 3 — GitHub token
    GITHUB_TOKENgithub.com/settings/tokens/new ↗
    1. The link pre-fills a classic PAT named template-builder with the repo scope checked.
    2. Set an expiry → Generate token → copy (ghp_…) → paste here. Built repos land in YOUR GitHub account.
